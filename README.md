## Dataset Description

### ADNet Dataset

- Dataset Scale: 20,590 images

- Image Size: 512×512 pixels

- Folder:  Train\Val\Test and Simple（Extract real‑noise）

- Data Type: Remote sensing images (adapted for denoising)
